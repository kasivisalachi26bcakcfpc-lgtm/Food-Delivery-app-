# 🍔 kasi visalachi – Food Delivery App

## 📌 Project Overview

**kasi visalachi** is a modern **Food Delivery App UI Design** created using **Figma**. The application is designed to provide users with a simple, attractive, and convenient way to discover restaurants, browse food items, add items to a cart, and place food orders.

The design focuses on a clean interface, easy navigation, attractive food visuals, and a smooth ordering experience.

---

## 🎯 Objective

The main objective of this project is to design a **user-friendly food delivery application** that makes it easy for users to:

*onboarding
*home page
*food page
*Cart page
*order confirm page
